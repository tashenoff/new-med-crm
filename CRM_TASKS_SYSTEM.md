# Система задач в CRM

## Описание
Добавлена система автоматических задач для заявок в CRM с возможностью назначения приема прямо из карточки заявки.

## Основные возможности

### 1. Автоматическое создание задачи
При создании новой заявки со статусом "Неразобранное" (NEW) автоматически создается задача:
- **Тип**: Звонок (CALL)
- **Название**: "Связаться с [Имя заявки]"
- **Описание**: Информация об источнике и контактных данных
- **Приоритет**: Высокий (если заявка срочная) или Средний
- **Срок**: 24 часа с момента создания
- **Ответственный**: Назначенный менеджер (если есть)

### 2. Назначение приема из заявки
Прямо из карточки заявки можно назначить прием к врачу:
- Выбирается врач и дата/время приема
- Автоматически создается пациент в HMS (если еще не создан)
- Создается запись на прием
- Статус заявки обновляется на "Связались" (CONTACTED)
- Заявка конвертируется в клиента

### 3. Просмотр задач по заявке
Для каждой заявки доступен список всех связанных задач с информацией:
- Название и описание
- Тип (звонок, встреча, email и т.д.)
- Приоритет (низкий, средний, высокий, срочный)
- Срок выполнения
- Статус (новая, в работе, выполнена, отменена, просрочена)

## Backend изменения

### Модели
- `backend/crm/models/task.py` - модель задачи с типами, статусами и приоритетами
- `backend/crm/models/lead.py` - модель заявки с полями для конве ртации

### Сервисы
- `backend/crm/services/task_service.py` - сервис для работы с задачами
- `backend/crm/services/lead_service.py` - добавлен метод `_create_initial_task()` для автоматического создания задачи

### API маршруты (`backend/crm/routes/leads.py`)
1. `GET /api/crm/leads/{lead_id}/tasks` - Получить задачи для заявки
2. `POST /api/crm/leads/{lead_id}/schedule-appointment` - Назначить прием из заявки

## Frontend изменения

### Хуки
- `frontend/src/hooks/useCrmApi.js` - добавлены методы:
  - `leads.getTasks(leadId)` - получить задачи заявки
  - `leads.scheduleAppointment(leadId, appointmentData)` - назначить прием
  - `tasks.*` - полный CRUD для задач

### Компоненты
- `frontend/src/components/crm/leads/EnhancedLeadsView.js` - отображает задачи и кнопку назначения приема

## Использование

### Создание заявки
```javascript
const leadData = {
  first_name: "Иван",
  last_name: "Петров",
  phone: "+77001234567",
  source: "website",
  priority: "medium"
};

const newLead = await createLead(leadData);
// Задача создастся автоматически
```

### Назначение приема
```javascript
const appointmentData = {
  doctor_id: "doctor-uuid",
  appointment_date: "2026-03-25T10:00:00",
  service: "Консультация",
  notes: "Первичный прием"
};

const result = await crmApi.leads.scheduleAppointment(leadId, appointmentData);
// Вернет: { patient_id, appointment_id, appointment_date }
```

### Получение задач
```javascript
const tasksData = await crmApi.leads.getTasks(leadId);
// Вернет: { lead_id, tasks: [...] }
```

## Типы задач
- `call` - Звонок
- `email` - Письмо  
- `meeting` - Встреча
- `follow_up` - Дозвон
- `note` - Заметка
- `custom` - Пользовательский тип

## Статусы задач
- `new` - Новая
- `in_progress` - В работе
- `completed` - Выполнена
- `cancelled` - Отменена
- `overdue` - Просрочена

## Приоритеты
- `low` - Низкий
- `medium` - Средний
- `high` - Высокий
- `urgent` - Срочный

## Workflow обработки заявки

1. **Новая заявка поступает** → Статус: NEW (Неразобранное)
   - ✅ Автоматически создается задача "Связаться с клиентом"
   
2. **Менеджер звонит клиенту** → Отмечает задачу выполненной

3. **Назначается прием** → Кнопка "Назначить прием"
   - ✅ Создается пациент в HMS
   - ✅ Создается запись на прием
   - ✅ Статус меняется на CONTACTED (Записан на прием)
   
4. **Прием подтвержден** → Статус: IN_PROGRESS (Запись подтверждена)

5. **Пациент пришел** → Статус: CONVERTED (Пациент пришел)

6. **Оплачено** → Статус: CLOSED (Оплачено)

## Примечания
- Задачи создаются только для новых заявок (статус NEW)
- Срок выполнения задачи - 24 часа
- При назначении приема заявка автоматически конвертируется в клиента
- Задачи привязаны к заявке через поле `lead_id`
