# Система Лояльности и Кэшбэка

## Описание

Полностью интегрированная система бонусов для пациентов и кэшбэка для врачей.

## Функциональность

### Бонусная система для пациентов

✅ **Начисление бонусов:**
- Автоматическое начисление после оплаты услуг
- Регулируемый процент (настраивается администратором)
- Бонусы не сгорают и не имеют срока действия
- Начисление происходит только после фактического оказания услуги

✅ **Использование бонусов:**
- Максимум 30% от суммы услуги можно оплатить бонусами
- Автоматический расчет доступного к использованию количества бонусов
- История всех бонусных операций

✅ **Отмена услуг:**
- При отмене приема бонусы автоматически возвращаются
- Если услуга не оказана - бонусы не начисляются

### Система кэшбэка для врачей

✅ **Начисление кэшбэка:**
- Процент от направленных и выполненных анализов
- Настраивается индивидуально для каждого вида анализа
- Кэшбэк начисляется только после оплаты анализа пациентом
- Связь с пациентом и услугой в истории

✅ **Отображение информации:**
- Текущий баланс кэшбэка врача
- История всех начислений
- Информация о пациенте и услуге для каждого начисления

## Автоматическая интеграция

### При оплате плана лечения

Когда статус payment_status меняется на "paid" в TreatmentPlan:

1. **Начисляются бонусы пациенту:**
   - Сумма: `paid_amount * earning_rate / 100`
   - Обновляется `patient.bonus_balance`
   - Создается запись в `bonus_transactions`

2. **Начисляется кэшбэк врачу:**
   - Проверяются все услуги в плане
   - Для каждой услуги с настроенным кэшбэком:
     - Сумма: `service_price * cashback_rate / 100`
     - Обновляется `doctor.cashback_balance`
     - Создается запись в `doctor_cashback_transactions`

### Использование бонусов при оплате

```javascript
// 1. Узнать сколько бонусов доступно
const bonusInfo = await fetch(`/api/loyalty/bonus/patient/${patientId}`)

// 2. Рассчитать использование
const calculation = await fetch('/api/loyalty/bonus/calculate', {
  method: 'POST',
  body: JSON.stringify({

    total_amount: 10000,  // Стоимость услуги
    requested_bonus: 5000  // Хочет использовать
  })
})
// Вернет: bonus_to_use, remaining_payment, patient_new_balance

// 3. Применить бонусы через LoyaltyService.spend_patient_bonus()
```

### Проверка кэшбэка врача

```javascript
// Получить баланс и историю

// Вернет: cashback_balance, total_earned, recent_transactions[]
```

## Бизнес-логика

### Правила начисления бонусов

1. Начисление происходит ПОСЛЕ оплаты
2. Если `payment_status ≠ "paid"` - бонусы не начисляются
3. Процент регулируется администратором
4. Бонусы не сгорают

### Правила использования бонусов

1. Максимум 30% от суммы услуги
2. Не больше доступного баланса
3. Формула: `bonus_to_use = min(requested, balance, total * 0.30)`

### Правила кэшбэка врачам

1. Кэшбэк только за АНАЛИЗЫ (лабораторные услуги)
2. Только после оплаты пациентом
3. Процент настраивается для каждого анализа
4. История связана с пациентом и услугой
