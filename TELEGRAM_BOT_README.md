# Telegram Bot для Medical CRM

Модульный Telegram бот с системой авторизации по номеру телефона и тремя ролями пользователей.

## 🚀 Возможности

- ✅ Авторизация по номеру телефона с кодом верификации
- 👥 Три роли пользователей: Администратор, Врач, Пациент
- 🔐 Автоматическое определение роли по номеру телефона
- 📱 Модульная архитектура
- 🗄️ Интеграция с MongoDB

## 📋 Роли и их команды

### 👤 Общие команды (для всех)
- `/start` - Начать работу с ботом
- `/help` - Справка по командам
- `/login` - Авторизация по номеру телефона
- `/profile` - Просмотр профиля
- `/logout` - Выход из системы

### 👨‍💼 Администратор
- `/stats` - Статистика системы
- `/users` - Список пользователей
- `/broadcast` - Рассылка сообщений

### 👨‍⚕️ Врач
- `/schedule` - Расписание
- `/appointments` - Приемы
- `/patients` - Пациенты

### 👤 Пациент
- `/book` - Записаться на прием
- `/myappointments` - Мои записи
- `/doctors` - Список врачей
- `/results` - Результаты анализов

## 🔐 Процесс авторизации

1. Пользователь отправляет команду `/login`
2. Бот запрашивает номер телефона
3. Пользователь отправляет номер или делится контактом
4. Бот генерирует 6-значный код и отправляет его пользователю
5. Пользователь вводит полученный код
6. Бот проверяет код и авторизует пользователя
7. Роль определяется автоматически:
   - Если ID совпадает с `TELEGRAM_ADMIN_ID` → Администратор
   - Если номер найден в коллекции `doctors` → Врач
   - Если номер найден в коллекции `patients` → Пациент
   - Если номер не найден → создается новый Пациент

## 🗄️ Коллекции MongoDB

### telegram_users
Хранит информацию о пользователях Telegram:
- `telegram_id` - ID пользователя в Telegram (уникальный)
- `phone_number` - Номер телефона
- `username` - Username в Telegram
- `first_name`, `last_name` - Имя и фамилия
- `role` - Роль: admin, doctor, patient
- `is_authorized` - Статус авторизации
- `patient_id` - Связь с пациентом (если роль patient)
- `doctor_id` - Связь с врачом (если роль doctor)

### verification_codes
Временные коды верификации:
- `phone_number` - Номер телефона
- `code` - Код верификации (6 цифр)
- `telegram_id` - ID пользователя
- `expires_at` - Время истечения (10 минут)
- `is_used` - Использован ли код

## 🔧 Настройки

В `backend/telegram_bot/config.py`:

```python
AUTH_CODE_LENGTH = 6                  # Длина кода авторизации
AUTH_CODE_EXPIRY_MINUTES = 10         # Время жизни кода (минуты)
```

## 🚦 Тестирование

### В режиме разработки
Коды верификации отправляются прямо в чат для удобства тестирования.

### В продакшене
Необходимо интегрировать SMS-шлюз в методе `generate_verification_code` в файле `database.py`.

## 🔄 Расширение функционала

Для добавления новых команд:

1. Создайте новый файл в `handlers/` (например, `patient_handlers.py`)
2. Определите обработчики команд
3. Зарегистрируйте их в `bot.py`:

```python
from .handlers.patient_handlers import book_appointment

application.add_handler(CommandHandler('book', book_appointment))
```
